# Donor sources

`default/` contains compact source exports of the author's approved engine and
FWD/RWD/AWD donors. JBeam, configuration, info and Automation design members are
retained byte-for-byte; meshes, textures and sound banks are omitted. These are
source donors, not generated upgrade parts or playable cars. The manifests pin
both the original archive SHA-256 and the compact archive SHA-256.

Drop your Automation ZIP exports into `custom/engines/` or `custom/drivetrains/`.
Place an export in both folders to offer both conversions independently. Updates
never ship or replace these folders. Only distribute exports you have permission
to redistribute. The bundled author-owned source data uses the project license.
