# BeamJoy-Revived: Motorsport Expansion — client mod

Players receive this client mod automatically when joining a server running
BJR:ME. Open Motorsport Expansion from BJR's side menu to upgrade, tune and race.
Server installation and generation are handled by the server owner.

[Source and documentation](https://github.com/Sillyw0rld/bjr-motorsport-expansion-public)
